## 4. Ghi chú triển khai Supabase

- File schema hiện tại là `supabase/esmery_v1_schema.sql`.
- Cần apply schema lên Supabase project thật để các bảng mới hoạt động:
  - `notifications`
  - `safety_settings`
  - update check constraint cho `timeline_events.type`
  - update policies cho `friend_requests`
- Nếu database cũ đã tồn tại, một số thay đổi `check constraint` có thể cần migration `alter table drop constraint/add constraint` thay vì chỉ chạy lại `create table if not exists`.
